The initializer installs this project-scoped enforcement even for an already initialized dataset. Generic memory HTTP writes/deletes also refuse these control keys; operators must use dedicated control endpoints. Runtime activation must follow the initializer so the SQL boundary exists before workers run. This is SQL enforcement under the existing least-privilege worker assumptions, not protection from a database administrator or a future deliberate permission elevation.

An injected fence-receipt failure rolled back the entire promotion transaction. Successful and repeated promotions preserved the original operator intent.
